## 简介

砚迹是一款**本地运行、无需网络**的打字练习软件。支持中英文打字练习、文章管理、多用户、历史记录等完整功能，所有数据存储在浏览器本地。

**在线体验**：[https://vicjax.github.io/yantrace/](https://vicjax.github.io/yantrace/)

## 快速开始

```bash
# 克隆项目
git clone https://github.com/vicjax/yantrace.git
cd yantrace

# 用 Live Server 打开
# VS Code: 右键 index.html → Open with Live Server

# 或用 Python
python -m http.server 8080
# 访问 http://localhost:8080
```

> 🚧 更多功能开发中，敬请期待...
> 
>⚠️ 项目使用 ES Module，必须通过 HTTP 服务器访问，不能直接用 file:// 协议打开。
