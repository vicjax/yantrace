## 版本历史

### v0.7.0 - 2026-08-16

**Added**
- 用户管理整合为右上角下拉菜单
- 首页可点击切换用户，其他页面只读
- 新建用户自动切换到新用户
- 删除用户前检查历史记录
- 添加/重命名/删除用户弹窗统一

**Changed**
- 用户管理从独立页面改为下拉菜单 + 弹窗交互

**Fixed**
- 弹窗内联校验，错误显示在输入框下方
- 历史记录列表滚动问题


### v0.6.0 - 2026-08-15

**Added**

- 设置页面重构（横向布局 + 滑块 + 主题按钮）
- 按键音效功能（5 种轴体音效 + 试听 + 关闭）
- 设置改为弹窗，顶部栏齿轮入口
- 打字音效改为物理按键触发

**Removed**
- 移除"默认模式"设置项
- 移除首页设置入口

**Fixed**
- 中文标点/空格音效修复
- 结果弹窗返回首页按钮修复
- 亮色主题样式补全


### v0.5.0 - 2026-08-10

- 历史记录模块优化（数据展示统一等）


### v0.4.0 - 2026-07-31
