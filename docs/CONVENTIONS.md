# 砚迹 - AI 开发约定


## 核心原则
- 解耦：模块间通过事件/接口通信，不直接操作内部状态
- 复用：同类页面共用模板，通过参数区分
- 去冗余：同一功能只写一次


## 开发流程
- 方案优先：先确认再写代码
- 先看代码：不假设、不猜测
- 最小改动：复用现有逻辑
- 回归测试：不改坏已有功能


## 交互约定
- 不确定就问：不猜，直接问我要代码
- 分步实施：复杂任务拆成小步骤
- 每步验证：改完立即测试


## 编码规范
- 文件名小写 · 类名 PascalCase · 方法 camelCase · 常量 UPPER_SNAKE_CASE
- DOM ID 不加前缀 · 模板通过参数复用
- 新增内容走策略模式，不改引擎核心
