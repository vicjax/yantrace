## 一、产品概述

### 1.1 产品定位

砚迹是一款**本地运行、开箱即用**的打字练习软件。用户打开浏览器即可练习中文/英文打字，所有数据存储在本地，无需网络，无需安装。

### 1.2 核心价值

| 价值         | 说明                                 |
| ------------ | ------------------------------------ |
| **隐私安全** | 数据只存在用户浏览器，开发者无法获取 |
| **开箱即用** | 无需安装，打开浏览器即可使用         |
| **轻量高效** | 零依赖，启动即用                     |
| **数据自主** | 用户完全掌控自己的练习数据           |

### 1.3 使用场景

用户打开浏览器 → 选择练习模式 → 开始打字 → 获得实时反馈 → 查看统计结果


## 二、用户画像

### 2.1 目标用户

| 用户类型      | 特征                 | 使用场景                 |
| ------------- | -------------------- | ------------------------ |
| 打字初学者    | 需要练习基础打字技能 | 日常练习，提升速度       |
| 学生/职场人士 | 需要提高打字效率     | 论文、报告、代码输入     |
| 多用户家庭    | 多人共用一台电脑     | 各自独立练习，互不干扰   |
| 中文学习者    | 练习中文输入         | 提高中文打字速度和准确率 |

### 2.2 用户痛点

| 痛点               | 解决方案           |
| ------------------ | ------------------ |
| 在线打字软件有广告 | 纯本地，无广告     |
| 数据存在云端不安全 | 数据只在本地       |
| 需要注册账号       | 无需注册，开箱即用 |
| 练习记录不保存     | 自动保存历史记录   |
| 不能自定义文章     | 提供文章管理功能   |

### 3.2 辅助功能（P1）

| 序号 | 功能     | 说明                               | 状态               |
| ---- | -------- | ---------------------------------- | ------------------ |
| 3    | 文章管理 | 增删改查文章（中英文）             | 搭建并优化✅ v0.4.0 |
| 4    | 历史记录 | 查看成绩、导出CSV、清空            | 搭建并优化✅ v0.5.0 |

### 3.3 暂不实现

| 功能         | 原因                   |
| ------------ | ---------------------- |
| 云端同步     | 本地应用，不涉及网络   |
| 用户登录注册 | 本地多用户，不需要登录 |
| 在线排行榜   | 本地应用，无社交功能   |
| 移动端APP    | 浏览器即可，暂不打包   |


## 四、交互流程

### 4.1 核心流程

````
用户进入首页
│
├── 打字练习（核心）
│ ├── 选择文章
│ ├── 开始打字
│ ├── 实时反馈（字符颜色变化、统计更新）
│ └── 完成弹窗（展示结果、保存历史）
│
├── 文章管理（准备材料）
│ ├── 中/英切换
│ ├── 列表查看
│ ├── 编辑/新建/删除
│ └── 保存/取消
│
└── 管理功能（辅助）
├── 用户管理（切换/添加/删除）
├── 历史记录（查看/导出/清空）
└── 设置（字体/高度/主题/默认模式）
````

### 4.2 打字练习流程（详细）

````
1.用户进入练习页
↓

2.下拉选择文章 → 文章加载到文章区
↓

3.开始打字
├── 中文：浮动输入框跟随字符，输入法（IME）支持
└── 英文：直接键盘输入，keydown 监听
↓

4.实时反馈
├── 正确：字符变绿
├── 错误：字符变红 + 背景色提示
├── 改正：字符变黄
└── 当前位置：蓝色高亮 + 脉冲动画
↓

5.统计实时更新
├── CPM（中文）/ WPM（英文）
├── KPM、KSPC
├── 准确率、退格率
├── 进度条
└── 峰值速度
↓

6打完全部字符 → 完成弹窗
├── 展示完整统计数据
├── 自动保存历史记录
└── 按钮：再来一次、复制结果、返回首页
````


### 4.3 文章管理流程

1.用户进入文章管理
↓

2.语言切换（中文 / English）
↓

3.左侧列表显示所有文章
↓

4.点击文章 → 右侧显示内容（查看模式）
↓

5.操作选项
├── 编辑 → 内容可编辑 → 修改 → 保存
├── 新建 → 空白编辑器 → 输入标题 → 输入内容 → 保存
└── 删除 → 确认 → 删除文章
↓

6.取消 → 回到查看模式



## 五、数据需求

### 5.1 数据结构

| 数据 | 字段 | 说明 |
|------|------|------|
| 文章 | id, title, content, type, createdAt, updatedAt | type: chinese/english |
| 用户 | id, name, createdAt | - |
| 历史记录 | id, userId, articleId, articleTitle, mode, stats, createdAt | mode: practice-cn/practice-en |
| 设置 | userId, defaultMode, fontSize, pageHeight, theme, updatedAt | - |

### 5.2 统计字段（只存原始数据）

| 字段 | 说明 |
|------|------|
| correct | 正确字符数 |
| errors | 错误字符数 |
| fixed | 改正字符数 |
| backspaces | 退格次数 |
| keystrokes | 总击键次数 |
| elapsed | 用时（秒） |

### 5.3 数据关系

````
用户（User）
│
├── 设置（Settings）─── 强依赖（1:1）
│
├── 历史记录（History）─── 强依赖（1:N）
│ │
│ └── 文章（Article）─── 弱关联（通过 articleId）
│
└── 文章（Article）─── 全局共享
````
