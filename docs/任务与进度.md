## 四、文件结构

```txt
YANTRANCE
│
├── app.js # 主入口，初始化协调
├── index.html # 首页 + 6个功能页面
├── style.css # 全局样式（暗色主题）
│
├── docs/ # 文档
│ ├── 任务与进度.md
│ ├── 规划.md
│ └── 设计.md
│
├── modules/ # 功能模块
│ ├── input.js # 录入引擎
│ ├── navigator.js # 导航：页面切换
│ ├── result.js # 结果管理
│ └── practice/ # 打字引擎
│ ├── index.js # 导出入口
│ ├── PracticeEngine.js # 核心引擎
│ ├── ChineseStrategy.js # 中文输入策略（浮动输入框）
│ └── EnglishStrategy.js # 英文输入策略（keydown）
│
├── services/ # 数据服务
│ ├── article.js # 文章库
│ ├── history.js # 历史记录
│ ├── settings.js # 设置
│ └── user.js # 用户管理
│
├── texts/ # 内置文章
│ ├── chinese/ # 中文文章（7篇）
│ └── english/ # 英文文章（3篇）
│
└── utils/ # 工具
├── helpers.js # 通用函数
├── stats.js # 统一统计服务
└── storage.js # localStorage 封装
```
