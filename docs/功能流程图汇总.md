## 一、导航模块（navigator.js）✅ 已完成

### 1.1 页面切换（goTo）

```
用户点击按钮 / 调用 goTo
    │
    ▼
navigator.goTo(pageId)
    │
    ├── 检查页面是否存在
    │
    ├── 隐藏所有页面（移除 active 类）
    │
    ├── 显示目标页面（添加 active 类）
    │
    ├── 更新 currentPage
    │
    ├── 触发 onPageChange 回调
    │
    └── 返回 true
```

### 1.2 页面切换回调（app.js）

```
onPageChange(pageId)
    │
    ├── 1. 离开当前页面（_leavePage）
    │   ├── 练习页 → practiceEngine.leave() → 清理策略
    │   └── 录入页 → inputEngine.leave()
    │
    └── 2. 进入目标页面（_enterPage）
        ├── 练习页 → practiceEngine.enter() → 加载文章
        ├── 录入页 → inputEngine.enter() → 加载文章列表
        ├── 历史记录 → resultManager.renderHistory()
        ├── 用户管理 → app._renderUserList()
        └── 设置 → app._loadSettings()
```

### 2.4 渲染文章（_renderArticle）


### 2.5 字符状态流转（_handleCharInput）

```
用户输入字符 → _handleCharInput(char)
    │
    ├── 获取当前字符 item = chars[currentCharIndex]
    │
    ├── 判断是否匹配 isMatch = (char === item.char)
    │
    ├── 获取当前状态和保留颜色
    │   ├── currentStatus = item.status
    │   ├── wasError = (item.keepColor === 'error')
    │   └── wasFixed = (item.keepColor === 'fixed')
    │
    ├── 状态转换（输入正确）
    │   ├── PENDING + 第一次输对 → CORRECT（绿色）
    │   ├── ERROR + 输对 → FIXED（黄色）← 错误后改正
    │   ├── FIXED + 输对 → FIXED（黄色保持不变）
    │   ├── CORRECT + 输对 → CORRECT（绿色保持不变）
    │   └── PENDING + (wasError 或 wasFixed) + 输对 → FIXED（黄色）← 退格后重输
    │
    ├── 状态转换（输入错误）
    │   ├── PENDING + 输错 → ERROR（红色）
    │   ├── CORRECT + 输错 → ERROR（红色）
    │   ├── FIXED + 输错 → ERROR（红色）
    │   └── ERROR + 输错 → ERROR（红色保持不变）
    │
    ├── 更新计数
    │   ├── correct（绿色字符数）
    │   ├── errors（红色字符数）
    │   └── fixed（黄色字符数）
    │
    ├── 清除保留颜色（item.keepColor = null）
    │
    ├── 更新状态（item.status = newStatus）
    │
    ├── currentCharIndex++
    │
    ├── _renderArticle() → 重新渲染
    │
    ├── _updateCurrentChar() → 更新高亮
    │
    ├── _updateProgressOnly() → 更新进度
    │
    ├── _samplePeakSpeed() → 采样峰值速度
    │   ├── 最小采样时间：15 秒后才开始记录
    │   ├── 采样间隔：每 10 秒采样一次
    │   └── 使用净速度（准确率惩罚后的速度）
    │
    ├── _updateFloatingInputPosition() → 更新浮动输入框位置
    │
    ├── _scrollToCurrentChar() → 滚动跟随
    │
    └── 检查是否完成 → 触发 onComplete
```

### 2.10 计时器管理（_startTimer / _stopTimer）

```
首次按键 / 恢复 → _startTimer()
    │
    ├── 检查是否已运行（_statsTimer）
    │
    ├── 判断首次还是恢复
    │   ├── _timerAccumulated === 0 → 首次启动
    │   │   └── startTime = Date.now()
    │   │   └── _timerStartTime = Date.now()
    │   └── _timerAccumulated > 0 → 从暂停处继续
    │       └── startTime = Date.now() - _timerAccumulated * 1000
    │       └── _timerStartTime = Date.now() - _timerAccumulated * 1000
    │
    ├── _timerPaused = false
    │
    └── _startStatsTimer() → 启动每秒定时器

失焦 / 切标签页 / 点击外部 → _stopTimer()
    │
    ├── 更新累计时间
    │   └── _timerAccumulated = (Date.now() - startTime) / 1000
    │
    ├── 清除定时器
    │   └── clearInterval(_statsTimer)
    │
    ├── _timerPaused = true
    │
    └── 更新计时显示
```

## 三、统一统计服务（stats.js）✅ 已完成

### 3.1 练习统计计算（calcPracticeStats）

```
各模块调用 → calcPracticeStats(data)
    │
    ├── 输入参数
    │   ├── correct / errors / fixed（字符状态）
    │   ├── backspaces / keystrokes（按键统计）
    │   ├── totalChars（文章总字符数）
    │   ├── startTime（开始时间戳）
    │   └── currentMode（'chinese' 或 'english'）
    │
    ├── 计算用时（elapsed）
    │
    ├── 计算速度
    │   ├── cpm = (correct + fixed) / minutes
    │   └── wpm = ((correct + fixed) / 5) / minutes
    │
    ├── 计算 kpm（击键速度）
    │   └── kpm = keystrokes / minutes
    │
    ├── 计算净速度
    │   ├── netCpm = cpm * (actualAccuracy / 100)
    │   └── netWpm = wpm * (actualAccuracy / 100)
    │
    ├── 计算正确率
    │   └── actualAccuracy = (correct + fixed) / (correct + errors + fixed)
    │
    ├── 计算效率指标
    │   ├── kspc = keystrokes / (correct + fixed)
    │   └── backspaceRate = backspaces / keystrokes
    │
    ├── 计算进度
    │   └── progress = (correct + errors + fixed) / totalChars
    │
    └── 返回完整统计对象
```



### 3.2 录入统计计算（calcInputStats）

```
录入模块调用 → calcInputStats(data)
    │
    ├── 输入参数
    │   ├── charCount（录入字符数）

    │   ├── backspaces（退格次数）
    │   ├── startTime（开始时间戳）
    │   └── currentMode（'chinese' 或 'english'）
    │
    ├── 计算速度（cpm / wpm）
    │
    ├── 计算 kpm
    │
    ├── 计算退格率
    │
    ├── 计算 kspc（每字符击键数）
    │
    └── 返回录入统计对象
```



### 3.3 时间格式化（formatTime）
