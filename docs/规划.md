# 砚迹(YanTrace) - 项目规划文档


## 一、项目概述

### 1.1 项目目标

做一个本地运行、开箱即用的打字练习软件。用户打开浏览器即可练习中文/英文打字，每次练习结果自动保存，支持多用户，所有数据存储在本地浏览器中。

### 1.2 使用场景

用户打开浏览器 -> 选择模式 -> 打字 -> 获得反馈 -> 查看统计


## 二、功能清单

### 2.1 核心功能（P0）

| 序号 | 功能         | 说明                                 |
| ---- | ------------ | ------------------------------------ |
| 1    | 中文打字练习 | 选文章 -> 照着打 -> 看对错 -> 看统计 |
| 2    | 英文打字练习 | 选文章 -> 照着打 -> 看对错 -> 看统计 |
| 3    | 中文文章录入 | 选文章追加 / 新建 -> 打字 -> 保存    |
| 4    | 英文文章录入 | 选文章追加 / 新建 -> 打字 -> 保存    |

### 2.2 辅助功能（P1）

| 序号 | 功能     | 说明                           |
| ---- | -------- | ------------------------------ |
| 5    | 用户管理 | 切换用户 / 添加用户 / 删除用户 |
| 6    | 历史记录 | 查看成绩 / 导出CSV / 清空      |
| 7    | 设置     | 改默认模式 / 字体大小 / 主题   |

### 2.3 不做的功能

| 功能         | 原因       |
| ------------ | ---------- |
| 云端同步     | 本地应用   |
| 用户登录注册 | 本地多用户 |
| 在线排行榜   | 本地应用   |
| 移动端APP    | 浏览器即可 |


## 三、模块划分

### 3.1 模块清单

| 模块     | 职责                                 | 依赖         | 对应功能           |
| -------- | ------------------------------------ | ------------ | ------------------ |
| 导航     | 页面切换（首页 <-> 各功能页面）      | 无           | 全部               |
| 打字引擎 | 渲染文章、接收输入、比对、统计、高亮 | 文章库       | 中文练习、英文练习 |
| 录入引擎 | 显示已有内容、接收输入、保存         | 文章库       | 中文录入、英文录入 |
| 结果管理 | 显示完成弹窗、自动保存历史           | 历史库、用户 | 全部练习模式       |
| 文章库   | 增删改查 + localStorage              | 存储         | 全部               |
| 用户管理 | 增删改查 + 切换 + localStorage       | 存储         | 用户管理           |
| 历史记录 | 增删改查 + 导出 + localStorage       | 存储、用户   | 历史记录           |
| 设置     | 读写偏好设置 + localStorage          | 存储、用户   | 设置               |
| 存储     | localStorage 统一读写接口            | 无           | 全部               |
| 工具     | 通用工具函数（防抖、格式化等）       | 无           | 全部               |


## 四、技术选型

| 项目 | 选型                        | 原因                     |
| ---- | --------------------------- | ------------------------ |
| 语言 | 原生 JavaScript (ES Module) | 无需构建，浏览器直接运行 |
| 样式 | 原生 CSS（暗色主题）        | 简单够用                 |
| 存储 | localStorage                | 数据量小，本地隔离       |
| 框架 | 无                          | 项目规模不需要           |
| 依赖 | 无                          | 保持轻量                 |

不引入：TypeScript、React/Vue、打包工具、npm 包


## 五、编码规范

### 5.1 命名

| 规范   | 说明             | 示例           |
| ------ | ---------------- | -------------- |
| 文件名 | 小写             | practice.js    |
| 类名   | PascalCase       | PracticeEngine |
| 函数名 | camelCase        | getArticles()  |
| 常量   | UPPER_SNAKE_CASE | STORAGE_KEY    |

### 5.2 注释

每个文件顶部说明职责，关键函数写注释说明参数和返回值。

示例：

```js
/**
 * 打字引擎模块
 * 职责：管理打字练习的核心逻辑
   */
   export default class PracticeEngine {
   /**
    * 加载文章
    * @param {string} content - 文章内容
      */
      load(content) { }
      }
```



### 5.3 导出

每个模块使用 export default 导出主类，工具函数使用具名导出。
