# 砚迹（YanTrace）- 详细设计文档


## 一、页面设计

### 1.1 页面关系

首页是唯一入口，其余 6 个页面通过首页按钮进入，彼此独立：

首页（page-home）
  │
  ├── 中文打字练习（page-practice-cn）
  ├── 英文打字练习（page-practice-en）
  ├── 中文文章录入（page-input-cn）
  ├── 英文文章录入（page-input-en）
  ├── 用户管理（page-user）
  ├── 历史记录（page-history）
  └── 设置（page-settings）

### 1.2 页面清单

| 页面         | ID               | 说明                         |
| ------------ | ---------------- | ---------------------------- |
| 首页         | page-home        | 四个大按钮 + 底部三个入口    |
| 中文打字练习 | page-practice-cn | 文章区 + 统计面板 + 进度条   |
| 英文打字练习 | page-practice-en | 文章区 + 统计面板 + 进度条   |
| 中文文章录入 | page-input-cn    | 下拉选文 + 已有内容 + 录入区 |
| 英文文章录入 | page-input-en    | 下拉选文 + 已有内容 + 录入区 |
| 用户管理     | page-user        | 用户列表 + 添加/切换/删除    |
| 历史记录     | page-history     | 历史列表 + 导出/清空         |
| 设置         | page-settings    | 默认模式 + 字体大小 + 主题   |

## 四、交互设计

### 4.1 输入方式

| 模式         | 输入方式                               | 速度指标 | 特殊处理               |
| ------------ | -------------------------------------- | -------- | ---------------------- |
| 中文打字练习 | compositionstart/end + 隐藏输入框      | CPM      | 输入框跟随当前字符位置 |
| 英文打字练习 | keydown                                | WPM      | 无输入框，直接监听     |
| 中文文章录入 | compositionstart/end + contenteditable | CPM      | 组合输入完成后上屏     |
| 英文文章录入 | keydown + contenteditable              | WPM      | 按键直接上屏           |

### 4.2 打字流程

1. 进入页面 -> 加载文章 -> 重置状态
2. 当前字符蓝色高亮
3. 用户输入 -> 比对字符
   - 正确：变绿，正确数+1
   - 错误：变红，错误数+1
4. 索引+1，高亮下一个字符
5. 实时更新统计
6. 全部完成 -> 弹窗 -> 自动保存历史

### 4.3 录入流程

1. 进入页面 -> 加载文章列表到下拉框
2. 用户选择已有文章 或 点击新建
   - 已有：显示已有内容（只读）
   - 新建：空白，无已有内容
3. 用户在录入区打字 -> 实时统计
4. 点击保存 -> 新建或追加 -> 刷新列表 -> 清空录入区

### 4.4 页面切换清理

| 离开的页面 | 清理动作       |
| ---------- | -------------- |
| 练习页     | 移除隐藏输入框 |
| 录入页     | 清空录入区内容 |
| 全部页面   | 无其他残留     |


## 五、运行逻辑

### 5.1 启动流程

1. 用户打开 index.html
2. app.js 初始化：
   - 初始化存储（检查 localStorage，创建默认数据）
   - 初始化用户（创建默认用户）
   - 初始化文章库（加载内置文章 + 用户文章）
   - 初始化导航（注册所有页面）
   - 初始化打字引擎
   - 初始化录入引擎
3. 显示首页

### 5.2 页面切换流程

1. 用户点击按钮
2. 导航.goTo(页面ID)
   - 所有页面隐藏（display: none）
   - 目标页面显示（display: block）
3. 触发对应模块：
   - 练习页 -> 打字引擎.enter()：加载文章，重置状态，聚焦输入
   - 录入页 -> 录入引擎.enter()：加载文章列表，重置状态
   - 用户管理 -> 用户服务.renderList()：渲染用户列表
   - 历史记录 -> 历史服务.renderList()：渲染历史列表
   - 设置 -> 设置服务.loadPreferences()：加载偏好设置

### 5.3 退出/离开清理

| 离开的页面     | 清理动作                     |
| -------------- | ---------------------------- |
| 练习页（中文） | 移除隐藏输入框，清空输入状态 |
| 录入页         | 清空录入区内容，重置统计     |
| 结果弹窗       | 无，已自动保存               |

### 6.2 模块依赖

- navigator.js：无依赖
- practice.js -> article.js -> storage.js
- input.js -> article.js -> storage.js
- result.js -> history.js + user.js -> storage.js
- user.js -> storage.js
- history.js -> storage.js -> user.js
- settings.js -> storage.js -> user.js
- storage.js：无依赖

### 6.3 数据流向

练习：用户输入 -> 打字引擎 -> 比对 -> 统计 -> 结果弹窗 -> 保存历史 -> localStorage

录入：用户输入 -> 录入引擎 -> 保存 -> 更新文章库 -> localStorage

## 八、异常处理

### 8.1 异常场景

| 场景                | 处理方式                             |
| ------------------- | ------------------------------------ |
| localStorage 不可用 | 提示用户检查浏览器设置，禁用保存功能 |
| 数据读取失败        | 使用默认空数据，页面正常显示         |
| 保存失败            | 提示用户重试                         |
| 文章库为空          | 显示"暂无文章，请先录入"             |
| 用户列表为空        | 自动创建默认用户                     |

### 8.2 数据校验

| 场景             | 处理方式                   |
| ---------------- | -------------------------- |
| 录入内容为空     | 保存时提示"没有内容可保存" |
| 新建文章标题为空 | 弹窗要求输入标题           |
| 删除最后一个用户 | 禁用删除按钮               |


## 九、性能考虑

| 场景              | 策略                       |
| ----------------- | -------------------------- |
| 长文章渲染        | innerHTML 批量更新         |
| 统计更新          | 每次按键更新（数据量小）   |
| localStorage 读写 | 直接读写                   |
| 页面切换          | 只切换 display，不重建 DOM |
| 事件监听          | 页面离开时移除监听         |
