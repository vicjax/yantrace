# 砚迹（YanTrace）- 详细设计文档


## 一、页面设计

### 1.1 页面关系

首页是唯一入口，其余 页面通过首页按钮进入，彼此独立：

首页（page-home）
  │
  ├── 中文打字练习（page-practice-cn）
  ├── 英文打字练习（page-practice-en）
  ├── 文章管理（page-article）
  ├── 用户管理（page-user）
  ├── 历史记录（page-history）
  └── 设置（page-settings）

### 1.2 页面清单

| 页面         | ID               | 说明                         |
| ------------ | ---------------- | ---------------------------- |
| 首页         | page-home        | 四个大按钮 + 底部三个入口    |
| 中文打字练习 | page-practice-cn | 文章区 + 统计面板 + 进度条   |
| 英文打字练习 | page-practice-en | 文章区 + 统计面板 + 进度条   |
| 文章管理     | page-article     | 下拉选文 + 已有内容 + 录入区 |
| 用户管理     | page-user        | 用户列表 + 添加/切换/删除    |
| 历史记录     | page-history     | 历史列表 + 导出/清空         |
| 设置         | page-settings    | 默认模式 + 字体大小 + 主题   |

## 三、交互设计

### 3.1 输入方式

| 模式         | 输入方式                              | 速度指标 | 特殊处理               |
| ------------ | ------------------------------------- | -------- | ---------------------- |
| 中文打字练习 | compositionstart/end + 可见浮动输入框 | CPM      | 输入框跟随当前字符位置 |
| 英文打字练习 | keydown                               | WPM      | 无输入框，直接监听     |

### 3.2 打字流程

1. 进入页面 -> 加载文章 -> 重置状态
2. 当前字符蓝色高亮
3. 用户输入 -> 比对字符
   - 正确：变绿，正确数+1
   - 错误：变红，错误数+1
4. 索引+1，高亮下一个字符
5. 实时更新统计
6. 全部完成 -> 弹窗 -> 自动保存历史



## 四、架构

### 4.1 MVP 分层

```text
用户操作 → View（视图层）→ Presenter（展示器层）→ Model（数据层）→ localStorage
```
| 层级 | 职责 | 目录 |
| ---- | ---- | ---- |
| View | 纯 DOM 渲染，事件转发 | views/ |
| Presenter | 业务逻辑，协调 M 和 V | presenters/ |
| Model | 数据读写，localStorage | services/ |
| Controller  | 路由协调，模块注册  | app.js |

### 4.2 数据流向   

````text
用户输入 → 策略层(keydown/composition) → 引擎层 → 统计 → 结果弹窗 → 保存历史 → localStorage 
````
